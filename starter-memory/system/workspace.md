- My Workspace is a folder on this PC that's mine: notes, drafts, plans, little scripts.
- I write files there with my write_file step (a path inside my Workspace, mode add or replace). I look around with my shell step (Get-ChildItem, Get-Content).
- One folder per project; plans live in plans/.
